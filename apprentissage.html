01 · Structure

HTML : organiser le contenu

HTML est le langage de balisage qui décrit la structure d'une page. Les balises donnent un sens au contenu : un titre, un paragraphe, une navigation, une image ou un lien.

À retenir

  • Utiliser des titres dans un ordre logique, de <h1> à <h6>.
  • Choisir des éléments sémantiques comme <header>, <main> et <footer>.
  • Décrire les images avec un texte alternatif pertinent dans alt.
<section>
    <h2>Mon sujet</h2>
    <p>Une première explication.</p>
</section>

02 · Présentation

CSS : mettre en forme une page

CSS contrôle l'apparence des éléments HTML : couleurs, espacements, tailles de texte et organisation de la page. Flexbox et Grid aident à créer des mises en page qui s'adaptent à différents écrans.

À retenir

  • Un sélecteur cible les éléments à modifier.
  • Les règles responsive adaptent la mise en page aux petits écrans.
  • Les classes permettent de réutiliser un même style à plusieurs endroits.
.carte {
    padding: 24px;
    background-color: white;
    display: grid;
    gap: 12px;
}

03 · Interactivité

JavaScript : rendre une page interactive

JavaScript permet de réagir aux actions des visiteurs et de modifier le contenu d'une page. On peut par exemple écouter un clic, vérifier un formulaire ou afficher un élément à la demande.

À retenir

  • Une variable conserve une valeur avec const ou let.
  • Une fonction regroupe une action que l'on peut réutiliser.
  • Un événement, comme click, déclenche du code.
const bouton = document.querySelector("#mon-bouton");

bouton.addEventListener("click", () => {
    alert("Bonjour !");
});

04 · Programmation

Python : apprendre la logique du code

Python est un langage polyvalent apprécié pour sa syntaxe lisible. Il peut servir à apprendre les bases de la programmation, automatiser des tâches ou développer des applications côté serveur.

À retenir

  • Les variables stockent des informations.
  • Les conditions permettent de choisir quelles instructions exécuter.
  • Les boucles répètent une action et les fonctions organisent le programme.
nom = "Noah"

if nom:
    print(f"Bonjour, {nom} !")
